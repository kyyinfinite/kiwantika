# KIWANTIKA media

Tambahkan aset visual opsional berikut ke folder ini:

- `kiwantika-logo.png` — logo utama transparan, dipakai di header.
- `kiwantika-hero.jpg` — foto utama/hero. Landscape, minimal 1600px lebar.
- `kiwantika-about.jpg` — foto pendukung untuk halaman Tentang (opsional).
- `kiwantika-gallery-01.jpg` dst. — dokumentasi kegiatan (untuk fase galeri).

Jika `kiwantika-logo.png` atau `kiwantika-hero.jpg` belum ada, tampilan tetap menggunakan fallback tanpa gambar rusak.
